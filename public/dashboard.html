Auth Concepts Demonstrated

Password hashing — bcryptjs hashes your password with salt rounds=12 before storing it.
JWT issuance — on login/register the server signs a token with a secret and sets an expiry.
Auth middleware — every request to /api/me passes through requireAuth, which verifies the token before allowing access.
Client-side token storage — the token is saved in localStorage and sent as a Bearer token on each API request.
HttpOnly cookie — the server also sets an HttpOnly cookie so the token is inaccessible to JavaScript on other origins.
